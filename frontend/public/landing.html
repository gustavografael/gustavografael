Firewall Check Point

NetGuardian

Dashboard para troubleshooting de firewalls Check Point via SSH. Execute health checks, valide roteamento em clusters HA, gere pacotes TAC e receba diagnóstico inteligente com cards coloridos por severidade.

🛡️

Verificar Saúde do Ambiente

Coleta CPU, memória, load, interfaces, erros RX/TX, CoreXL, SecureXL, disco, cluster, logs e sessões.

  • Cards verde, amarelo e vermelho por severidade
  • Diagnóstico inteligente com correlação de eventos
  • Exportação do relatório em Markdown
🔀

Validar Roteamento HA

Identifica active/standby com cphaprob stat, compara rotas e prepara correção com confirmação.

  • Diff entre caixas do cluster
  • Plano de correção antes de aplicar
  • Replicação segura de rotas estáticas
📦

Gerar Pacote TAC

Executa cpinfo, cpview export, coleta logs e dumps, e gera um .tar.gz para download.

  • Pacote pronto para abertura de chamado
  • Coleta remota via SSH
  • Download direto pelo navegador

Como usar na sua máquina

A interface pode ficar publicada na Internet, mas os testes SSH saem do Local Agent na estação do analista — ideal para VPN e redes internas. 

git clone https://github.com/gustavografael/gustavografael.git
cd gustavografael
npm install
npm run start:local

# Abra no navegador:
# http://localhost:5173
